## 📸 Overview
![Teaser](./static/images/framework.png)

**PersonaVLM** is an innovative agent framework that transforms general-purpose MLLMs into personalized assistants. It features a proactive multimodal memory architecture and a Momentum-based Personality Evolving Mechanism (PEM) to ensure deep alignment with users over long-term interactions.

## 📊 Persona-MME Benchmark
We introduce **Persona-MME**, a comprehensive evaluation benchmark with 2,000+ curated cases assessing 14 fine-grained personalization capabilities across seven key aspects.
